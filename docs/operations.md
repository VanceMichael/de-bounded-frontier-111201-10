# 本地运行说明

先运行单元测试，再执行演示命令。演示从干净临时目录发起真实请求并处理响应，不需要外部站点。
常规导入失败时返回非零退出码，事务中的原文和记录会一起回滚，可保留源文件再次处理。
查询模式只读取当前数据库，不会补采或删除来源数据。需要长期保留证据时，请备份整个数据库。
本地响应服务支持状态码、响应头、文本或 base64 字节正文；未配置路径返回未找到。
每条路径的脚本独立推进，最后一个响应会重复；可借请求记录核对调用顺序。
数据文件的路径均相对项目根目录，修改工作目录前请确认输入和数据库参数。

## 发现前沿运行

`crawl` 与 `frontier` 共用一个前沿数据库（建议 `var/frontier.sqlite3`），可分次执行、跨进程续跑。
许可版本通过 `--license-version` 选择，默认采用许可文件中的最新版本；
每次运行开始都会用当前许可重检未完结地址，不再授权的队列地址转记为拒绝，不会发出请求。
`--limit` 限制本次运行的页面抓取数，便于分批推进；总预算按许可口径累计实际请求（页面与 robots），
耗尽后剩余队列标记 `exhausted/budget_exhausted`，提高预算或新版本许可后再次运行即可继续。
`--mirror` 把许可 origin 映射到本地镜像地址，策略判定始终针对原始许可地址；
`frontier --state <状态>` 按 queued/visited/denied/paused/exhausted 过滤查看理由。
`crawl-demo` 一次性演示上述流程并打印镜像侧请求记录，可作为拒绝地址零请求的核对证据。
